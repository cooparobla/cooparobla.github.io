toyengine

A modern C++20 / Vulkan 3D game engine with a Blender-style editor.

C++20VulkanMoltenVKLinuxmacOSYAML scenes

toyengine pairs a full-resolution deferred PBR renderer with rigid-body and cloth physics, dynamic water, streamed procedural terrain, an interactive UI toolkit and a native editor that writes exactly the files the game loads. It is adaptable by design: scenes, objects, materials and render settings are plain YAML, every rendering feature has quality tiers and a master switch, and each subsystem is its own library that can be lifted out and used elsewhere.

What's inside

Rendering, simulation and worlds

Rendering

  • Deferred PBR: Cook-Torrance with directional, point and spot lights
  • Cascaded shadows, soft PCF, PCSS and contact shadows
  • Hi-Z SSR, traced SSGI, temporally stable SSAO
  • SDF raymarching that mixes with meshes; volumetric light shafts
  • Bloom, auto exposure, LUTs, physical DoF, TAA / SMAA / FXAA
  • Optional cel bands, outlines, dithering and palette quantisation

Water

  • Lakes and oceans with Gerstner waves
  • The same wave math runs in the shader and in a CPU query, so gameplay matches visuals
  • Rivers whose current follows the mesh slope and bends around obstacles
  • Shoreline foam and ripple rings; Buoyancy floats any rigid body
  • Underwater fog, absorption, caustics, Snell's window

Physics

  • Box, sphere, capsule and triangle-mesh colliders
  • Physics materials, hinge joints, triggers, collision layers
  • Kinematic movers and character controllers

Cloth

  • XPBD cloth that collides with the world
  • Renders as a shaded, shadow-casting mesh

Procedural terrain

  • A seeded mapcoopa world with elevation, biomes and rivers
  • Meshed in chunks on the job system, streamed around the camera
  • Tile shapes are mesh assets, so one line of YAML changes the look

UI toolkit

  • Panels, text, buttons, sliders, progress bars, layouts, masks
  • Crisp screen-space HUDs, or world-space canvases that stay clickable in 3D

toyengine_editor

An editor that feels like Blender

The editor embeds the real engine, so its Full Render viewport is the game's renderer. Blender's keymaps, gizmos, modes and outliner, with Unity's component model.

  • Scenes and object assets. Hierarchy, inspector, gizmos, and play / pause / step in place. Prefab-style assets are instanced with prefab:.
  • Mesh modelling. Extrude, inset, bevel, loop cut, bridge, Catmull-Clark subdivide, mirror and UVs. Sculpting with draw, smooth, inflate, grab and flatten.
  • Material lookdev. Shader ball, studio lighting, turntable.
  • Build › Package. Turns a project into compact .caml binaries.
  • Plain files. Everything saves as YAML in assets/, ready to hand-edit, diff and merge.

Data-driven

A scene is a file you can read

Scenes are trees of objects with components, written in YAML. The demo scenes are heavily commented and double as the reference for every component, and config.yaml has a comment on every key. Packaged builds use binary .caml (Zstandard + AES-256-GCM), and every loader reads both, so nothing needs path rewriting.

$git clone --recurse-submodules git@github.com:cooparobla/toyengine.git
$cmake -B build && cmake --build build -j
$./build/toyengine water_test
$./build/toyengine_editor

On macOS, run tools/setup_macos.sh once first to install MoltenVK, the Vulkan loader, glslc and GLFW.

The coopa stack

Seven libraries, stacked like bricks

toyengine sits on pinned submodules. Each is C++20, mostly header-only, builds standalone, and is useful without the engine.

toyengine

The engine and editor: render pipeline, water, streamed world, gameplay components.

gfxcoopa

Vulkan, from RAII device objects up to a deferred PBR renderer.

physxcoopa

Real-time rigid-body and cloth physics.

uicoopa

Anchored retained widgets, a fluent builder and an immediate-mode layer for tools.

sfxcoopa

Game audio with a bus mixer and binaural 3D sound.

mapcoopa

Seeded fantasy worlds: 33 biomes, rivers, roads, nations, towns and caves.

libcoopa

The shared runtime: work-stealing jobs, scene graph, async assets with hot reload, coroutines.

caml

YAML stored as compressed, encrypted .caml files. Library and CLI.
