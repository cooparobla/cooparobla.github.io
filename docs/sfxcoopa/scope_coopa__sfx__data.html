read_smpl_loops

std::vector< SampleLoop > coopa::sfx::data::read_smpl_loops(const std::string &path)

Reads all sample-loop markers from a wav file's smpl chunk, if present.

Walks the RIFF chunk list rather than assuming fmt sits at a fixed offset files exported by Pro Tools/Reaper commonly lead with a JUNK padding chunk, which breaks naive parsers that assume fmt is the first chunk after the 12-byte RIFF/WAVE header. Also honours the RIFF rule that every chunk is padded to an even byte count.

Parameters

Parameter Type Default Description
path const std::string & Filesystem path to a .wav file.
Returns: std::vector< SampleLoop >
