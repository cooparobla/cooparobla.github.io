class Resampler

Defined in: /Users/tblaney/Code/toyengine/libs/sfxcoopa/sfxcoopa/dsp/resampler.h

Converts between sample rates (and applies pitch shift) via a 4-point Catmull-Rom cubic Hermite interpolator.

Cubic Hermite needs samples at fractional-position offsets -1, 0, +1, +2 relative to its read cursor, so it must retain history/lookahead state across process() calls rather than treating each call's input in isolation otherwise the very first and last few output samples of every chunk would be wrong, and chunking the same input differently would produce different output. Internally this is a single buffer of not-yet-fully-consumed input, front-compacted (never reallocated once its initial capacity is reserved) as the read cursor advances past samples no future tap will need again.

process

void process(const float *in, uint32_t in_frames, uint32_t &in_consumed, float *out, uint32_t out_frames, uint32_t &out_written)

Consumes input and produces output, both up to the given counts.

Always accepts (buffers) the entirety of in in_consumed is always in_frames. out_written may be less than out_frames if not enough input has been supplied yet (across this and prior calls) to compute further output samples; call again with more input to continue. For a single whole-buffer conversion (e.g. AudioClip::load, which has the entire file in memory), pad the input with a couple of trailing repeated samples before the final call so the last output samples which need lookahead past the true end of the file can still be produced.
