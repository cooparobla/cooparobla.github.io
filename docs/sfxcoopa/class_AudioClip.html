class AudioClip

Defined in: /Users/tblaney/Code/toyengine/libs/sfxcoopa/sfxcoopa/data/audio_clip.h

Owns a clip's fully-decoded PCM data at a chosen engine format.

Constructed only via load(): a Decoder is opened at the source's own native channel count and the requested rate, so miniaudio's own f32-at- matching-rate passthrough (proven bit-exact in Decoder's tests) is what makes the AudioClip-level decode a straight copy whenever the source already matches the engine's rate there is no separate "fast path" branch here to get wrong, it falls out of always asking Decoder for exactly the channel count it needs. force_mono is the one case Decoder can't do alone: it's applied as an explicit downmix pass afterward.

Non-copyable (owns a potentially large PCM buffer), movable. Shared across voices via std::shared_ptr, cached by path+settings in the engine (see AudioEngine::load_clip in core/engine.h).
