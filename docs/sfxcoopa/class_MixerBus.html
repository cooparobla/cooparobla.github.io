class MixerBus

Defined in: /Users/tblaney/Code/toyengine/libs/sfxcoopa/sfxcoopa/mixer/bus.h

One node of the mix graph. Voices write directly into a bus's own scratch buffer (via scratch()); the bus then recursively pulls in its children, runs its effect chain, and applies its own gain so a bus always publishes an already gain-and-effect-applied result for whichever bus reads it next (its parent, or Mixer for the root).

Solo is resolved globally and control-side via recompute_effective_mutes(): whenever any bus anywhere in the graph has solo() true, every bus that is not that bus, an ancestor of it, or a descendant of it becomes effectively muted for that render computed once so the audio thread only ever reads the precomputed effective_mute() flag, never scans graph state itself.

Non-copyable, non-movable: children_ store raw pointers to sibling MixerBus instances by address, which a copy or move would invalidate. Mixer owns all MixerBus instances behind stable-address unique_ptrs for exactly this reason.

static recompute_effective_mutes

static void recompute_effective_mutes(const std::vector< MixerBus * > &all_buses)

Recomputes effective_mute() for every bus in all_buses (main-thread only). If any bus has solo() true, a bus is kept audible only if it is a soloed bus, is an ancestor of one (so the soloed signal still has a path up to the root), or is a descendant of one (soloing a bus means "this and everything under it") every other bus becomes effectively muted. With no solo active anywhere, effective_mute() is just each bus's own mute() flag.

A naive "mute everything that isn't itself soloed" rule is wrong here: it would also mute the soloed bus's own ancestors, silencing the very signal the solo was meant to isolate before it ever reaches the root.
