class Image

Defined in: /Users/tblaney/Code/toyengine/libs/mapcoopa/coopa/maps/image.h

An 8-bit-per-channel image with interleaved components, origin top-left.

Deliberately not a texture: libcoopa carries no graphics dependency, so this is a buffer a consumer can upload, encode or discard as it likes.

set_pixel

void set_pixel(int x, int y, const glm::vec4 &color)

Writes one pixel including its alpha, ignoring coordinates outside the image.

The overload that makes a 4-channel image usable at all. reset() zeroes the buffer, so an RGBA layer starts fully transparent and only the marks actually drawn onto it become opaque which is what lets the road, structure and landmark layers be stacked over the terrain without carrying a background of their own.

Parameters

Parameter Type Default Description
x int Column.

color const glm::vec4 & The colour to write, in 0-255 component range; clamped. The alpha component is dropped on a 3-channel image.
