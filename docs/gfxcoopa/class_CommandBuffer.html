class CommandBuffer

Defined in: /Users/tblaney/Code/toyengine/libs/gfxcoopa/gfxcoopa/command/command_buffer.h

Non-owning wrapper around VkCommandBuffer providing named recording methods.

Intended to be used as a short-lived object during a frame: CommandBuffercmd(raw_vk_cmd); cmd.begin(); cmd.begin_render_pass(render_pass,framebuffer,extent,clear_color); cmd.bind_pipeline(pipeline); cmd.bind_vertex_buffer(vertex_buffer); cmd.set_viewport(0,0,w,h); cmd.draw(3);//triangle cmd.end_render_pass(); cmd.end();

bind_descriptor_set

void bind_descriptor_set(const pipeline::DescriptorSet &set, uint32_t set_index=0)

Binds a descriptor set to the graphics pipeline, using the layout of the most recently bound pipeline (see bind_pipeline()) no caller-supplied VkPipelineLayout needed.

set is the first parameter (not set_index, unlike the raw overload above) deliberately: a literal 0 is a valid null-pointer constant, so it converts to both this overload's set_index (uint32_t) and the raw overload's pipeline_layout (VkPipelineLayout) equally well, which makes bind_descriptor_set(0, set) genuinely ambiguous between the two. Putting set (a DescriptorSet&, which cannot convert to VkPipelineLayout at all) first rules the raw overload out as a candidate whenever this one is meant, at the cost of the two overloads' set_index parameter not lining up positionally.

Parameters

Parameter Type Default Description
set const pipeline::DescriptorSet & The descriptor set to bind.
set_index uint32_t 0 The descriptor set index (binding point).

transition

void transition(memory::Image &image, TextureUsage to)

Transitions an image to a new TextureUsage, inferring the correct access/pipeline-stage masks (and, via the image's own Format, the correct aspect mask) automatically.

There is no "from" parameter: the source usage is read from memory::Image::current_usage() and updated afterward, so the caller cannot describe a transition the image is not actually in.

Parameters

Parameter Type Default Description
image memory::Image & The image to transition. Must be a single-mip, single-layer image (memory::Image's only supported shape).
to TextureUsage The usage to transition into.
