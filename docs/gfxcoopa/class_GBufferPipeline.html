class GBufferPipeline

Defined in: /Users/tblaney/Code/toyengine/libs/gfxcoopa/gfxcoopa/engine/passes/gbuffer_pipeline.h

The pipelines that rasterize opaque and alpha-masked geometry into the G-buffer's four colour attachments.

Holds the stock back-face-culled pipeline, a no-cull sibling, and one variant per named SurfaceShaderDesc registered through add_variant(). bind() selects between them by material shader name.

add_variant

void add_variant(const std::string &name, const std::string &vert_spv, const std::string &frag_spv, coopa::gfx::CullMode cull)

Registers a derived shader's own vertex/fragment pair as a named variant, reusing this pipeline's layout (same descriptor sets, same push-constant range) only the shader modules and rasterization cull mode differ.

Called once per SurfaceShaderDesc of SurfaceShaderDomain::Opaque at construction time (see PixelRenderPipeline's ctor), never mid-frame an unresolvable or duplicate name is a startup error via the Shader ctor / std::map's behaviour, not a runtime one, matching this codebase's startup-vs-runtime tier policy (render_features.h).

Parameters

Parameter Type Default Description
name const std::string & The SurfaceShaderDesc's name; must be non-empty and not already registered (asserted via GFX_VK_CHECK-style hard failure is unnecessary here a duplicate simply overwrites, which can't happen because SurfaceShaderRegistry::add() already rejects duplicates before this is ever called).
vert_spv const std::string & Resolved .spv path for this shader's G-buffer vertex entry point.
frag_spv const std::string & Resolved .spv path for this shader's G-buffer fragment entry point.
cull coopa::gfx::CullMode Rasterization cull mode override (e.g. CullMode::None for two-sided foliage cards).
