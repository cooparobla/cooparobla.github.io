class RoutinePromise

Defined in: /Users/tblaney/Code/toyengine/libs/libcoopa/coopa/routine/routine.h

The coroutine promise behind Routine. Holds whatever the body last yielded, plus any exception that escaped it.

Defined ahead of Routine so std::coroutine_handle<RoutinePromise> is only ever instantiated against a complete type; the three members that need Routine itself are defined below the class.

const initial_suspend

std::suspend_always initial_suspend() const noexcept

Suspends before the first statement of the body.

The body therefore does not run at construction, which keeps a Routine safe to move around before it is started. RoutineRunner::start() does the first resume immediately, reproducing Unity's "StartCoroutine runs the body synchronously up to the first yield return".

Returns: std::suspend_always
