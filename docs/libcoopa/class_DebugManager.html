class DebugManager

Defined in: /Users/tblaney/Code/toyengine/libs/libcoopa/coopa/debug/manager.h

Manager class that collects, sorts, and prints queue-based diagnostic logs.

Collects under a [JOBS] scope. See DebugBucket for the unscoped equivalent.

Provided for consumers; libcoopa itself does not log through it.
