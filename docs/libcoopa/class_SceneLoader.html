class SceneLoader

Defined in: /Users/tblaney/Code/toyengine/libs/libcoopa/coopa/scene/scene_loader.h

Parses a YAML scene file into a Scene, dispatching component parsing to registered callbacks.

Usage: `//Onceatstartup,fromwhichevermoduledefineseachcomponent: SceneLoader::register_component_parser("MeshRenderer",&{ auto*mr=obj.templateadd_component(); //...populatemrfromnode,resolvingrelativeassetpathsviactx.resolve(path)... });

Scenescene=SceneLoader::load("assets/scenes/cube/scene.yaml");`

Builds a scene from an already-parsed (not yet inheritance-resolved) document.

The in-memory twin of load(): an editor keeps the scene document it is editing as a node and rebuilds the live Scene from it without a round trip through disk. path is where the document lives (or will live) it anchors relative asset paths and inherit_from references exactly as load() would; base documents are still read from disk.

Builds one object (and its subtree) from an already-resolved object node.

For an editor rebuilding a single edited object in place. The returned object is not started and belongs to no scene; the caller parents it (Scene::add_root_object() + Scene::adopt(), or SceneObject::add_child()) and then calls start().

static register_component_parser

static void register_component_parser(const std::string &name, ComponentParser fn)

Registers a parser for a component's YAML tag/type name.

Lets libraries outside libcoopa (e.g. gfxcoopa, uicoopa) extend scene loading without SceneLoader depending on them. Registering the same name twice replaces the previous parser. Names are matched after normalization: a leading '!' is stripped, so registering "MeshRenderer" matches both a "!MeshRenderer" YAML tag and a "type: MeshRenderer" key. The built-in name ("Transform") cannot be overridden — it is handled before the registry is consulted.

Parameters

Parameter Type Default Description
name const std::string & Component name as it appears in the scene file, with or without a leading '!'.
fn ComponentParser Parser invoked when a component node resolves to this name.

static clear_component_parsers

static void clear_component_parsers()

Clears every registered component parser.

Registered parsers commonly capture references (e.g. a Device or Allocator) by reference in their closures; call this before those referenced objects are destroyed to avoid dangling captures surviving into a later SceneLoader::load() call.
