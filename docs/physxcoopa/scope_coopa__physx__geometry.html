closest_points_segment_segment

void coopa::physx::geometry::closest_points_segment_segment(const glm::vec3 &p1, const glm::vec3 &q1, const glm::vec3 &p2, const glm::vec3 &q2, glm::vec3 &c1, glm::vec3 &c2)

Finds the closest points between two segments [p1,q1] and [p2,q2].

Standard clamped-parametric approach (Ericson, "Real-Time Collision Detection", 5.1.9), with the near-parallel-segments branch handled explicitly: when the segments' direction vectors are (near-)parallel, the general 2x2 linear system used to solve for both parameters simultaneously becomes singular (its determinant denom below tends to zero), so that branch instead fixes s = 0 (the start of the first segment) and solves for t alone.

Parameters

Parameter Type Default Description
p1 const glm::vec3 & First segment's start.
q1 const glm::vec3 & First segment's end.
p2 const glm::vec3 & Second segment's start.
q2 const glm::vec3 & Second segment's end.
c1 glm::vec3 & Output: closest point on the first segment.
c2 glm::vec3 & Output: closest point on the second segment.

closest_point_on_obb

glm::vec3 coopa::physx::geometry::closest_point_on_obb(const glm::vec3 &point, const OBB &box)

Finds the closest point on (or in) an OBB's surface/volume to a world-space point.

Projects the point into the box's local frame, clamps each axis to [-half_extent, half_extent], then transforms back to world space. When point is inside the box, this returns point itself (the clamp is a no-op on every axis) callers that need a surface point for an interior query should treat a zero/near-zero (point - result) distance as "penetrating" separately.

Parameters

Parameter Type Default Description
point const glm::vec3 & World-space query point.
box const OBB & Box to query against.
Returns: glm::vec3
