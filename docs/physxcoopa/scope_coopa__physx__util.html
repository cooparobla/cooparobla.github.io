orthonormal_basis

void coopa::physx::util::orthonormal_basis(const glm::vec3 &n, glm::vec3 &t1, glm::vec3 &t2)

Builds an orthonormal basis {n, t1, t2} from a unit normal, for friction directions.

Uses the branch-free construction (Duff et al., "Building an Orthonormal Basis, Revisited"): picks the tangent whose cross product with n cannot degenerate, based on the sign of n.z.

Parameters

Parameter Type Default Description
n const glm::vec3 & Unit normal (not re-normalized caller must pass a unit vector).
t1 glm::vec3 & Output: first unit tangent, perpendicular to `n`.
t2 glm::vec3 & Output: second unit tangent, perpendicular to both `n` and `t1`.
