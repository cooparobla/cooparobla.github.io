class BodyId

Defined in: /Users/tblaney/Code/toyengine/libs/physxcoopa/physxcoopa/dynamics/body.h

Generational handle into PhysicsWorld's body array.

Shape mirrors coopa::job::JobHandle's current design ({index, generation}, libcoopa's handle.h:459-461) both exist to stop a stale handle from addressing a slot recycled by someone else. BodyId's version is simpler than JobHandle's: it needs only a plain, non-atomic generation bump checked serially, since v1's body array is touched only from physxcoopa's single owning thread, never JobHandle's lock-free multi-producer free list.
