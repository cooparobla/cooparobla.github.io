class PhysicsSettings

Defined in: /Users/tblaney/Code/toyengine/libs/physxcoopa/physxcoopa/util/physics_settings.h

Everything a scene's physics: YAML block can configure, applied once to a PhysicsWorld by apply_physics_settings() (called from install_physics_system()).

Attributes / Member Variables

Name Type Default Description
solver PhysicsConfig {}

Solver/broadphase tunables (velocity_iterations, fixed_dt, ...).
gravity glm::vec3 {0.0f, 0.0f, k_gravity_z}
layer_names std::vector< std::string >

Layer names, index == layer id (0..31). Lets scene YAML write layer: "Ground" instead of a bare integer see physx_yaml.h's layer-name registry, seeded from this list.
ignore_pairs std::vector< std::pair< uint32_t, uint32_t > >

Layer-id pairs whose collision is turned OFF (every pair collides by default).
debug_draw debug::DebugDrawFlags debug::DebugDrawFlags::None

Debug geometry PhysicsSystem should gather every frame by default (see PhysicsWorld::debug_draw()); the render layer may still override this at runtime.
parallel_threshold std::size_t 64

Minimum bound-collider count before PhysicsSystem's job-parallel passes (Phase 3) dispatch instead of running serially mirrors toyengine's JobsConfig::parallel_threshold idiom.
