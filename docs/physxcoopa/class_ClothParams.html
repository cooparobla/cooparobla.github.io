class ClothParams

Defined in: /Users/tblaney/Code/toyengine/libs/physxcoopa/physxcoopa/cloth/cloth.h

Per-cloth tunables. Field names and defaults track Unity's Cloth component where an equivalent exists, so a value copied from a Unity inspector behaves recognisably here.

Attributes / Member Variables

Name Type Default Description
stretch_compliance float 0.0f

Stretch compliance in m/N inverse stiffness. 0 is fully inextensible and is the right default: XPBD is stable at zero compliance, unlike a spring at infinite k. Raise toward 1e-4 for a stretchy knit.
bend_compliance float 5e-5f

Bend compliance in m/N. Non-zero by default because a perfectly rigid bend makes a sheet behave like sheet metal it will not crease or fold over a sphere. 5e-5 reads as a mid-weight fabric; 1e-3 is silk, 1e-6 is leather.
damping float 0.05f

Velocity damping, applied implicitly as v = 1/(1 + dampingh) the same form dynamics::integrate_forces() uses for Body::linear_drag, and for the same reason: the explicit form v = (1 - dampingh) goes unstable (sign-flips the velocity) once damping*h exceeds 1, which a user typing a large number into a scene file will hit.
thickness float 0.03f

Collision thickness in metres: particles are held this far off a collider's surface. The sheet is a zero-thickness triangle mesh, so without an offset the RENDERED surface sits exactly on the collider and z-fights it. Unity calls this the same.
friction float 0.5f

Coulomb friction coefficient at cloth-collider contacts, applied positionally (see cloth_solver.h). 0 slides freely off a sphere; 1 grips.
gravity_scale float 1.0f

Multiplier on the world gravity vector; 0 makes a weightless banner.
max_velocity float 100.0f

Hard speed clamp, mirroring PhysicsConfig::max_linear_velocity. A safety net against a single bad frame (a teleporting anchor body) launching the sheet.
external_acceleration glm::vec3 {0.0f}

Constant acceleration added to gravity. Unity's "External Acceleration".
wind glm::vec3 {0.0f}

Wind velocity in m/s. Wind is a VELOCITY, not an acceleration: the aerodynamic force below depends on the cloth's motion RELATIVE to the air, so a sheet already moving with the wind feels nothing from it which is what makes a banner settle into a steady flutter instead of accelerating forever.
wind_turbulence float 0.0f

Peak magnitude of a smooth deterministic gust added to wind. Unity's "Random Acceleration". Deterministic (driven by the solver's own time accumulator, not rand()) so the determinism harness still passes.
air_drag float 0.02f

Aerodynamic drag coefficient the component of the per-triangle force along the face normal. This is what makes a sheet parachute rather than knife downward.
air_lift float 0.02f

Aerodynamic lift coefficient the tangential component. What makes a falling sheet slip sideways and flutter instead of dropping straight.
self_collision bool false

Enables particle-vs-particle separation so the sheet cannot pass through itself. Off by default: it is the single most expensive stage (a spatial hash rebuild plus a 27-cell scan per particle per substep) and a sheet draped over a convex body rarely needs it. Turn on for anything that folds onto itself.
self_distance float 0.0f

Minimum particle separation enforced by self-collision. 0 means "derive it at build time" cloth_builder.h sets it to 0.6x the grid's rest spacing, the largest value that cannot fight the structural constraints it shares particles with.
tether_scale float 1.02f

Tether slack factor. 1.0 is a perfectly inextensible tether, which looks rigid; 1.02 allows 2% stretch so the sheet still reads as fabric while its far corners stay put. Raise to disable tethers in practice, or clear Cloth::tethers outright.
substeps uint32_t 0

Cloth substeps per physics substep; 0 inherits PhysicsConfig::cloth_substeps.
iterations uint32_t 0

Constraint iterations per cloth substep; 0 inherits PhysicsConfig::cloth_iterations. 1 is right for small-substep XPBD the paper's central result is that spending a fixed budget on more substeps converges better than on more iterations.
sleep_threshold float 0.05f

Max particle speed (m/s) that still counts as "settled" for sleeping.
sleep_time float 0.5f

Seconds below sleep_threshold before the cloth stops simulating.
layer uint32_t 0

Collision layer index, tested against each shape's layer through the world's LayerMatrix the same matrix rigid pairs use, so one scene-level setting governs both.
