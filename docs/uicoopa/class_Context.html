class Context

Defined in: /Users/tblaney/Code/toyengine/libs/uicoopa/uicoopa/immediate/imm.h

All immediate-mode state: ids, hover/active tracking, layout, popups, text editing.

One Context per window. Call begin_frame()/end_frame() around each frame's declarations.
